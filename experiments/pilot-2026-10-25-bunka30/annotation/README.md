# 注釈シート

`annotations.csv` に、`docs/注釈ガイド_v0_2026-10-25.md` の規則で1単位1行を記入する。1コメントに複数の単位があれば `unit-no` を 2, 3, … と増やして行を足す。原文は書かない（受付番号で参照）。

列：comment-id, unit-no, claim（主張）, reason（理由。なければ「なし」）, reason-group（理由群の名前）, condition（条件。なければ「なし」）, condition-group, confidence（high/low）, note（迷った点）

記入後に `python3 -I -c` 等で理由群ごとの件数を集計する（集計スクリプトは注釈が終わってから作る）。
