# 卒論の進め方と書き方（2つの手引きをこの研究に当てはめたもの）

作成日：2026年10月15日。参考にした手引きは次の2つ。どちらも「研究室・指導教員の指示が優先」としているので、服部先生・SFCの指定（形式、分量、締切）が分かりしだい、そちらに合わせて直す。

- 坂間千秋「卒論の書き方」（和歌山大学、2019年2月更新） https://web.wakayama-u.ac.jp/~sakama/sotsuron/sotsuron.html
- 中田亨「やればできる卒論の書き方」（2003年初版、2009年改訂） https://researchmap.jp/blogs/blog_entries/view/77082/0eb9a69b5e4a770751c9f9b0f7f315d0?frame_id=836719

## 1. 進め方

| 手引きの考え方 | この研究での実行 |
|---|---|
| 論文の構想を先に立ててから実験する（中田） | 実験の前に、下の仮目次と「結論表」の空欄を作る。表を埋めるのに必要な実験だけを行う |
| 速戦速勝。複数の新しい変化を同時に試さない（中田） | 1ツール（広聴AI）・1モデル・1データ（文化庁パブコメ）に固定する。変える条件は抽出プロンプト（既定と意味を保つ指示）の1つだけ |
| まず手を動かし、アイデアは早く具体化する（中田） | 予備実験30件を10月中に一度通す。完璧な注釈ルールを待たない |
| 草稿を教員に見せ、修正を繰り返す。修正には最低1週間（坂間） | 1月8日の初稿から2月1日まで約3週間ある。教員の確認を2回受けられる日程にする |
| バックアップを必ず取る（坂間） | 原稿・注釈データ・実行結果をgitなどで版管理し、別の場所にも複製する |
| 日頃の取り組みが内容に出る（坂間） | 週ごとに作業記録（何をして、何が分かったか）を残す。進捗発表と論文の材料になる |

## 2. 書く順序（中田：易しいものから、広く浅く）

1. **謝辞**：最後に書くと思われがちだが、最も易しい。
2. **図と写真**：先に作る。図の量が論文の量をほぼ決める。この研究で必要な図は、広聴AIの処理の流れ、段階ごとの保持率、データの内訳、誤りの例。
3. **結論表**：研究課題と結果を1つの表にまとめる。最初は結果欄を空けておく。
4. **道具の説明メモ**：広聴AI（固定コミット、公式CLI、設定ファイル）の仕組みと、各段階の出力ファイル。
5. **実験メモ**：目的・手順・結果・考察の形で、予備実験の時点から書き溜める。
6. **参考文献メモ**：先行研究調査の文書から、本文で実際に引用するものだけを選ぶ。
7. **その他**（序論の背景、考察の文章）。

一つの章を深く書き込むより、全章を薄く書いてから厚くしていく。

## 3. 仮目次

見出しは「序論」のような一般語ではなく、内容が分かる言葉にする（中田）。章の役割は坂間の5章構成に合わせた。

| 章 | 仮の見出し | 書くこと |
|---|---|---|
| 要旨 | ― | 500〜600字。何の問題に、何をして、何が分かったか（坂間） |
| 1 | AIによる意見集約で少数の理由はどこで消えるか | 行政でのAI活用の背景、先行研究の長所と限界を公平に書く、研究課題の絞り込み、論文の構成 |
| 2 | 低頻度の理由・条件と広聴AIの処理 | 用語の定義（低頻度の理由群、理由・条件、段階）、広聴AIの抽出→クラスタ→要約の仕組み |
| 3 | 文化庁パブコメを用いた段階別の追跡方法 | データの選び方と制約、注釈の手順、実行条件（モデル、プロンプト、回数） |
| 4 | 段階ごとの保持率と脱落の傾向 | 実験の目的・手順・結果。少数の理由と頻出の理由の比較 |
| 5 | 理由・条件が失われる原因と研究の限界 | 誤り分析、関連研究との比較、限界（投稿者が特定できない、注釈者が1人など）と改善案 |
| 6 | 結論と今後の課題 | 結論表、読者が他人に一言で説明できるまとめ |
| ― | 謝辞・参考文献・付録 | 付録にはプロンプト全文、注釈ガイド、設定ファイルを入れる |

## 4. 文章の決まり

- 文末は「である」「する」。「〜と思われる」「〜だろう」は避け、根拠を添えて「〜と考えられる」とする（坂間）。
- 客観的な事実と自分の評価を同じ文に混ぜない（中田）。
- 論文・章・段落の冒頭に要点を置く。読者の注意は冒頭に集まる（中田）。
- 同じ内容を繰り返さない。どの話の流れにも乗らない話題は削るか付録に回す（中田）。
- 文献を丸写しせず、2つ以上の文献を読んで自分の言葉でまとめる。そのまま使う部分は鉤括弧で囲み出典を示す（坂間）。
- 参考文献は本文で引用したものだけ。教科書やWebページに偏らず、査読論文を中心にする。Webページには参照年月を書く（坂間・中田）。
- グラフには単位と、ばらつき（3回実行の幅など）を示す（坂間・中田）。

## 5. 避けること（坂間の「よくある失敗」から）

- **背景ばかりで本論が薄い**：先行研究は既に約35件集めたので、序論に詰め込みすぎない。厚くするのは第3〜5章。
- **図や余白でページを埋める**：長さは内容で決まる（中田）。
- **参考文献が少ない・Web中心**：引用は査読論文を優先する。
- **発表スライドの文字が多い、時間超過**：10分なら表紙以外で15枚前後が目安。

## 6. これから決めること

- 服部先生・SFCの論文形式（分量、書式、テンプレート、提出物）。
- 要旨の字数指定の有無。
- 進捗発表（約3回）の日程と、各回で見せるもの。
